# farmwatch

Telegram-бот для моніторингу ферми 3D-принтерів Bambu Lab.

Бот підключається до десктопного застосунку **Bambu Farm Manager Client** через
Chrome DevTools Protocol (CDP/WebSocket), зчитує статус принтерів зі сторінки
дашборда й надсилає сповіщення в Telegram.

## Можливості

- 📊 Статус ферми з авто-оновленням повідомлення
- 📋 Список принтерів і детальна інформація по кожному (прогрес, файл, температури, час)
- 🔔 Сповіщення: завершення друку, зміна статусу, підключення / відключення принтера, періодичні зведення
- ⚙️ Налаштування прямо з бота: інтервал оновлення, типи сповіщень, proxy
- 👥 Білий список користувачів і груп (перший, хто напише `/start`, стає адміном)
- 🌐 Підтримка HTTP / SOCKS5 proxy

## Готова збірка (Windows, portable)

У вкладці **Releases**:
- `farmwatch X.Y.Z` — релізи на теги `vX.Y.Z`, файл `farmwatch-X.Y.Z-windows.zip`;
- `latest` — prerelease, що оновлюється на кожен пуш у `main`; кожна збірка має
  унікальну версію `X.Y.Z-dev.<коміт>` (`farmwatch-X.Y.Z-dev.<коміт>-windows.zip`).

У zip два exe (Python не потрібен):
- `farmwatch-X.Y.Z.exe`: консольний бот;
- `farmwatch-gui-X.Y.Z.exe`: панель налаштувань з живими метриками, що ховається в трей.

`config.json` створюється автоматично поруч з exe при першому запуску, якщо його ще нема.
Запусти `farmwatch-gui`, впиши токен у панелі та збережи; або відредагуй `config.json` руками і запусти консольний `farmwatch`.

## Вимоги (запуск з вихідного коду)

- Windows
- Python 3.10+
- Встановлений **Bambu Farm Manager Client**
- Токен Telegram-бота від [@BotFather](https://t.me/BotFather)

## Встановлення

```bash
git clone <repo-url>
cd <repo>
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Налаштування

1. Скопіюйте `config.example.json` у `config.json`.
2. Впишіть `telegram.bot_token`.
3. За потреби змініть `monitor.exe_path` — шлях до `Bambu Farm Manager Client.exe`.
4. `allowed_users` і `allowed_groups` можна лишити порожніми:
   - перший користувач, який напише боту `/start` у приваті, додається як адмін;
   - група додається автоматично після команди `/start`, надісланої в ній.

`config.json` містить токен і **не комітиться** (він у `.gitignore`).

## Запуск

```bash
.venv\Scripts\python.exe telegram_bot.py
```

або просто запустіть `run.bat` — він сам створить віртуальне оточення та
встановить залежності, якщо їх немає.

## Панель налаштувань (v2)

Графічна панель для керування самим farmwatch: редагування `config.json`
(токен, користувачі, групи, proxy, монітор, сповіщення), статус бота, перегляд
логів і діагностики зникнення принтерів. Відкривається в **окремому вікні**:

```bash
.venv\Scripts\python.exe -m web.gui
```

Або у браузері (`http://127.0.0.1:8000`):

```bash
.venv\Scripts\python.exe -m web.server
```

Панель не дублює Bambu Farm Client, вона лише налаштовує програму. Потрібні
`fastapi`, `uvicorn`, `pywebview` (вже у `requirements.txt`; на Windows вікно
малюється через вбудований Edge WebView2).

## Команди бота

| Команда     | Опис                                                |
|-------------|-----------------------------------------------------|
| `/start`    | Головне меню                                        |
| `/status`   | Статус ферми (повідомлення оновлюється автоматично) |
| `/printers` | Список принтерів і деталі по кожному                |
| `/settings` | Налаштування бота                                   |
| `/restart`  | Перезапуск моніторингу                              |
| `/id`       | Дізнатись свій user/chat ID                          |
| `/version`  | Версія бота                                          |
| `/help`     | Довідка                                             |

## Структура

| Файл                 | Призначення                                                          |
|----------------------|----------------------------------------------------------------------|
| `telegram_bot.py`    | Бот: команди, обробники callback'ів, відправка сповіщень, lifecycle  |
| `printer_monitor.py` | Моніторинг принтерів через CDP/WebSocket, парсинг сторінки дашборда   |
| `run.bat`            | Скрипт запуску для Windows                                            |
| `config.example.json`| Шаблон конфігурації                                                   |
| `version.py`         | Версія проєкту (`__version__`) — оновлюйте перед тегом `vX.Y.Z` (CI звіряє) |
| `web/`               | Панель налаштувань v2 (FastAPI + статичний фронтенд): config.json, статус, логи, діагностика |

## Примітки

- Bambu Farm Manager Client має бути запущений з параметром
  `--remote-debugging-port` — за замовчуванням бот запускає його сам
  (`monitor.auto_launch: true`). Якщо застосунок уже відкритий без debug-порту,
  його потрібно закрити, щоб бот міг перезапустити його з потрібним прапорцем.
- Логи пишуться у `telegram_bot.log` і `printer_monitor.log` (вони в `.gitignore`).
